# Lab 4: Validators

## Adding New Fields

Once you have completed the initial redesign of the forms library, extend the application by adding the following fields and their corresponding validation rules:

| Field | Validation rules |
| --- | --- |
| Product code | Exactly 4 characters |
| Postal code | Exactly 5 digits |
| Age | Digits only; greater than 18 |
| Salary | Digits only; greater than 21,000 and less than 80,000 |
| Location | Either Oviedo, Gijón, Avilés, or a valid postal code |
| Discount code | Either text or a 3-digit number |
